# Text Summarization

## Description

Text Summarization is a Natural Language Processing application that creates a short summary from a given paragraph.

This project uses word frequency to identify the most important sentence in the input text.

## Technology Used

- Python
- Natural Language Processing
- Regular Expressions

## Requirements

Python 3.x

## Installation

No external libraries are required.

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

python app.py

4. Enter a paragraph.
5. The application displays the original text and summary.

## Example

### Input

Artificial intelligence is a rapidly growing technology. It is used in healthcare and education. Artificial intelligence allows computers to perform intelligent tasks.

### Output

Summary:

Artificial intelligence is a rapidly growing technology.

## Conclusion

This project demonstrates a simple method of text summarization using Python and Natural Language Processing concepts.
